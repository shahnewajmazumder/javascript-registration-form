
# JavaScript Registration Form with MongoDB

A full-stack user registration application built with HTML, CSS, JavaScript, Node.js, Express, and MongoDB. The project demonstrates client-side form validation, server-side validation, and secure password hashing.

## Features

- **Responsive user interface** with a modern design.
- **Form validation** for full name, email, phone number, password, and password confirmation.
- **Client-side validation** using JavaScript.
- **Server-side validation** using Express.
- **MongoDB integration** to store registered users.
- **Password security** using bcrypt hashing.
- **Duplicate email prevention** using a unique database index.
- **Registration feedback** for successful submissions and errors.
- **Automatic timestamps** to record when a user registers.

## Requirements

Before running the application, install:

- [Node.js](https://nodejs.org/)
- [MongoDB Community Server](https://www.mongodb.com/try/download/community)
- [MongoDB Compass](https://www.mongodb.com/try/download/compass) (optional, for viewing database records)

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/shahnewajmazumder/javascript-registration-form.git
cd javascript-registration-form
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start MongoDB

Ensure your local MongoDB server is running. The application uses this connection string:

```text
mongodb://127.0.0.1:27017
```

### 4. Configure the database

The application connects to the database named `registrationDB` and uses the `users` collection.

The server creates the collection's unique email index when it starts. You can inspect registered records using MongoDB Compass.

### 5. Start the application

```bash
node server.js
```

### 6. Open the registration form

Visit the following URL in your browser:

```text
http://localhost:3000
```

## Validation Rules

The form validates the following information:

| Field | Validation |
|---|---|
| Full name | Must contain at least 2 characters |
| Email | Must have a valid email format |
| Phone number | Must be a valid 10-digit Indian mobile number beginning with 6–9 |
| Password | Must contain at least 8 characters |
| Confirm password | Must match the password |

The server also validates submitted information before saving it to the database.

## How It Works

1. The user fills in the registration form.
2. JavaScript validates the submitted information in the browser.
3. The form sends a request to the Express backend.
4. The backend validates the data again.
5. The password is hashed using bcrypt.
6. MongoDB stores the user record in `registrationDB.users`.
7. The application returns a success or error message.

## Database Record

A registered user document will contain fields similar to the following. The password field stores a **bcrypt hash**, not the original password.

```json
{
  "_id": "MongoDB-generated ObjectId",
  "name": "Example User",
  "email": "example@example.com",
  "phone": "9876543210",
  "password": "bcrypt-hash",
  "createdAt": "registration timestamp"
}
```

The exact `_id` and timestamp are generated by the application or database.

## Security Notes

- Passwords should never be stored in plain text.
- Server-side validation is necessary even when browser validation exists.
- The unique email index helps prevent duplicate email addresses.
- Do not commit passwords, API keys, or other secrets to GitHub.
- For production deployment, use HTTPS, secure configuration, rate limiting, and appropriate database access controls.
